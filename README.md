# 🌾 Semeando Atitudes, Colhendo um Mundo Verde 🌍

> **Projeto desenvolvido para o Concurso Agrinho**
> Um site interativo e responsivo construído com HTML5, CSS3 e JavaScript para conscientizar e engajar a comunidade sobre práticas sustentáveis no campo e na cidade.

---

## 📌 Sobre o Projeto

O projeto **"Semeando Atitudes, Colhendo um Mundo Verde"** é uma plataforma web criada com o objetivo de disseminar informações sobre sustentabilidade, agricultura consciente e preservação ambiental. Alinhado com a proposta do Concurso Agrinho, o site busca inspirar pequenas mudanças no dia a dia que geram grandes impactos no futuro do nosso planeta.

## 🚀 Funcionalidades

* **Página Inicial Dinâmica:** Apresentação impactante do tema com navegação intuitiva.
* **Conteúdo Educativo:** Seções dedicadas a práticas sustentáveis (conservação do solo, uso da água, reciclagem e agricultura familiar).
* **Quiz Interativo (JavaScript):** Um jogo de perguntas e respostas para testar os conhecimentos dos visitantes sobre o meio ambiente de forma divertida.
* **Design Responsivo:** Interface que se adapta perfeitamente a computadores, tablets e celulares.

## 🛠️ Tecnologias Utilizadas

O site foi desenvolvido do zero, utilizando as tecnologias fundamentais da web:

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **CSS3:** Estilização visual, animações e responsividade (Layout fluido e Flexbox/Grid).
* **JavaScript (Vanilla):** Lógica do quiz interativo, manipulação do DOM e dinamismo da página.
